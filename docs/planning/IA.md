# IA

## 1. 원칙

이 도구의 IA는 작업 수행 중심이다. 메뉴와 화면은 최소화한다.

필요한 흐름:

1. 작업을 만든다.
2. 변환을 실행한다.
3. 결과를 검수한다.
4. Notion에 발행한다.
5. 이전 작업을 다시 연다.

## 2. 화면 구조

| 화면 | 경로 | 목적 |
| --- | --- | --- |
| 작업 리스트 | `/` | 모든 변환 작업 확인, 실행, 결과 진입 |
| 작업 생성 | `/tasks/new` 또는 리스트 내 패널 | PPT 업로드와 Notion 대상 지정 |
| 작업 결과 | `/tasks/[taskId]` | 변환 결과 확인과 발행 |
| 슬라이드 검수 | `/tasks/[taskId]/slides/[slideId]` | 슬라이드별 crop/분류/블록 검수 |

## 3. 작업 리스트

첫 화면.

구성:

- 새 작업 만들기
- 작업명
- 원본 PPT 파일명
- 상태
- 마지막 실행일
- 실행
- 결과 보기
- 재실행

## 4. 작업 생성

구성:

- PPT 파일 업로드
- Notion 대상 입력
  - 기존 페이지 URL
  - DB/data source ID
- 변환 방식
  - 기존 페이지 업데이트
  - 새 하위 페이지 생성
- 작업 생성 버튼

## 5. 작업 결과

구성:

- 작업 상태
- 원본 PPT 정보
- Notion 대상
- 슬라이드 목록
- 변환 요약
  - 텍스트 블록 수
  - 이미지 후보 수
  - QR 후보 수
  - 표 후보 수
  - 검수 필요 항목 수
- Notion 발행 버튼

## 6. 슬라이드 검수

좌우 구조를 기본으로 한다.

왼쪽:

- 원본 슬라이드 렌더 이미지
- 감지된 객체 overlay
- crop 후보 표시

오른쪽:

- 추출 텍스트
- 이미지/QR/표 후보 목록
- 후보 분류 변경
- Notion block preview
- 저장

## 7. 제외 화면

- 통계 대시보드
- 조직 관리
- 권한 관리
- 알림 센터
- 댓글/승인 화면

이 항목들은 MVP 범위에 넣지 않는다.
