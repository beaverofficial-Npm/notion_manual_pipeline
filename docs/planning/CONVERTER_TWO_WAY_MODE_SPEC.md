# PPT→Notion 변환기 — 투웨이 모드 스펙 (그룹 베이크)

작성 2026-06-26. 기존 캡쳐 모드는 그대로 두고, **그룹 베이크 모드**를 한 웹 앱 안의 두 번째 모드로 추가한다. 김보일(제품기획팀) 노션화 검토 3이슈를 수용기준으로 흡수한다.

## 1. 배경·문제
기존 변환은 "슬라이드 렌더 → 크롭존 휴리스틱 추정 → 크롭 검수"다. 크롭존 추정이 **미그룹핑 슬라이드에서 그림을 깨뜨리고**(이슈2), 넘버링·페이지 구분 품질 문제가 있다(이슈1·3). 제작자가 PPT에서 요소를 **그룹핑**하면, 그 그룹 경계를 신뢰해 정확히 한 장으로 구울 수 있음이 검증됐다(`매뉴얼 이미지 테스트.pptx` → 화살표·배지 포함 2200×1416 한 장 베이크 성공).

## 2. 두 모드 정의

| | 캡쳐 모드(기존) | 그룹 베이크 모드(신규) |
|---|---|---|
| 이미지 | 슬라이드 렌더 → 크롭존 추정 크롭 | 그룹 bbox로 정확히 베이크(추정 0) |
| 검수 | 크롭 검수 화면 | **변환 즉시 Notion 미리보기**(이미지 포함)에서 수정 |
| 전제 | 없음(아무 PPT) | 제작자가 시각요소를 그룹핑 |
| 적합 | 그룹 안 된 임의 deck | 매뉴얼 규약을 따르는 deck |

두 모드는 **동일 웹 앱**에 공존하며, **업로드 시 선택**한다(토글/라디오). 기본값 = 캡쳐(기존 보존).

## 3. 그룹 베이크 동작
1. **1순위 크롭 = 이미지박스 구간 그대로(+걸침 합집합)** (확정 2026-07-13, `BOX_CAPTURE_HANDOFF.md` — 재논의 금지).
   - 이미지박스 = 슬라이드(또는 slideLayout)의 **텍스트 없는 큰 채움 rect**(v2 덱: slideLayout5의 `#F2F2F2` 판, 좌 3.6%→우 64.3%, 상 17.1%→하 86.6%). `parseImageBoxes`가 슬라이드→레이아웃 순으로 탐지.
   - 크롭 경계 = 박스 ∪ 박스와 **겹치는** 이미지(areaRatio ≥ 0.005) ∪ 겹치는 짧은 라벨 shape(≤20자, 뱃지류) + 0.8% 패딩 (`boxCaptureRect` — 프로덕션·테스트 공용).
   - 콘텐츠 범위를 추정해 깎는 로직(콘텐츠 타이트 크롭·우측 클램프)은 시각 덩어리를 관통해 **폐기**.
2. 이미지박스가 없으면 2순위: 최상위 `<p:grpSp>` 의 `grpSpPr/a:xfrm`(off·ext, EMU) → 슬라이드 크기(`p:sldSz`) 대비 비율로 그룹 bbox 크롭 = **그룹당 한 장**. 그룹도 없으면 3순위: 휴리스틱 이미지 영역.
3. 슬라이드 렌더(soffice→pdf→pdftoppm) → 위 bbox 영역 크롭(화살표·배지·말풍선·다중 이미지 합성 보존).
4. 크롭 영역 밖 PPT 텍스트(`<a:t>`)는 추출해 **Notion 텍스트 블록**으로(편집·검색 가능).
5. **크롭 영역 안 텍스트는 픽셀로만**(결정 A) — 본문은 박스 밖에 두는 작성 규약 전제. 라벨·주석만 이미지에 구움.

## 4. 작성 규약 (그룹 베이크 모드 입력 계약)
- 시각자료(스크린샷+빨간 콜아웃 박스+숫자 뱃지+화살표+말풍선)는 **이미지박스(연회색 판) 위에** 배치한다 — 분리 불가 한 장으로 캡처됨.
- 본문/설명 텍스트는 **박스 밖 우측 컬럼**(x 66.9%~) PPT 텍스트로 둔다(편집·검색 위해).
- 말풍선·주석이 본문 텍스트 컬럼을 침범하지 않게 한다(침범분은 걸침 합집합으로 포함되나 본문 조각이 함께 찍힐 수 있음).
- 넘버링은 제작자가 명시한 그대로 둔다(도구가 재번호 안 함).

## 5. 수용기준 (AC) — 김보일 3이슈 포함
- **AC1 (넘버링 일치)**: 이미지 주석 번호(①②③)와 설명 텍스트 번호가 1:1 일치. 도구는 **원본 넘버링 토큰 보존**, 자동 재번호(1,2,3…) 금지, 텍스트 순서 재정렬 금지.
- **AC2 (그림 무손실)**: 그룹 베이크 이미지가 깨지지 않음 — 그룹 경계 기준 크롭이라 합성 분해·오크롭 0. 다중 이미지+화살표가 한 장에 온전.
- **AC3 (페이지 구분)**: PPT 페이지(또는 기능) 단위마다 Notion `divider` + 명확한 heading 삽입으로 구분.
- **AC4 (텍스트 커버리지)**: 슬라이드의 모든 `<a:t>` 중 "그룹 밖" 텍스트가 블록으로 누락 0. 누락 시 미리보기에 경고 목록 표시.
- **AC5 (미리보기 우선)**: 그룹 베이크 모드는 변환 완료 즉시 이미지 포함 Notion 미리보기를 제시. 검수=미리보기 수정.

## 6. 텍스트 커버리지 게이트
PPTX XML의 `<a:t>` 전수 = 그라운드 트루스. "그룹 밖 텍스트" vs "생성된 블록" diff → 누락을 *목록으로* 산출(추측 아님). 그룹 안 텍스트는 픽셀 의도이므로 누락 대상에서 제외. 미리보기에 "누락 N건" 경고.

## 7. 흐름 (그룹 베이크 모드)
```
업로드(모드=그룹베이크) → 그룹 베이크(이미지) + 텍스트 추출 + 커버리지 체크
  → Notion 미리보기(이미지+블록+divider) 즉시 제시
  → 사람이 미리보기에서 수정
  → 발행(이때 Notion 대상 입력 — 별도 UX 항목과 연계)
```

## 8. 범위·비범위
- 범위: 그룹 베이크 이미지, 그룹밖 텍스트 블록화, 넘버링 보존, 페이지 divider, 커버리지 체크, 미리보기 우선 흐름, 모드 선택 UX.
- 비범위(후속): 그룹 안 텍스트 OCR 검색레이어(결정 B 보류), 미그룹핑 deck 자동 그룹 추론, UNO shape-export(현재는 렌더+그룹bbox 크롭으로 충분).
