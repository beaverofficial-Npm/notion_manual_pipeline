# PPT to Notion Conversion Rules

## 1. 기본 원칙

PPT를 그대로 이미지화하지 않는다. Notion에서 읽고 수정할 수 있는 내용은 Notion 블록으로 옮기고, 화면 증거가 필요한 부분만 이미지로 사용한다.

## 2. 요소별 처리 기준

| PPT 요소 | 처리 방식 |
| --- | --- |
| 제목 | Notion heading |
| 단계 설명 | Numbered list |
| 보조 설명 | Bullet list |
| 주의/TIP | Callout |
| 앱 화면 | 이미지 영역만 crop |
| QR | QR 단위로 별도 crop |
| 표 | Notion table 우선 |
| 설명 텍스트가 포함된 전체 슬라이드 | 기본 제외 |
| 화살표 | 기본 제외, 필요 시 Notion 텍스트 흐름으로 표현 |
| 강조 박스/번호 | 화면 이해에 필요하면 이미지에 포함 |

## 3. 이미지 크롭 기준

### 허용

- 앱 화면만 들어간 이미지
- QR 코드만 들어간 이미지
- 표를 Notion table로 변환할 수 없을 때 표 영역만 crop
- 화면 위의 번호/강조 박스가 의미를 설명하는 경우

### 제외

- 오른쪽/왼쪽 본문 설명까지 포함된 슬라이드 전체 crop
- 이미 Notion 텍스트로 옮긴 문장 영역
- 화살표만 있는 넓은 여백
- 장식 요소

## 4. 다운로드 페이지 예시 기준

- 휴대폰 화면: 스토어 검색, 설치, 설치 완료 화면을 하나의 이미지 그룹으로 처리
- Android QR: 별도 이미지
- IOS QR: 별도 이미지
- 다운로드 링크: Notion bullet로 제공

## 5. 상품 페이지 예시 기준

- `판매상품 검색`: 화면 이미지 조각만 사용하고 화살표는 제외
- `판매상품 품절`: 앱 화면 흐름 이미지는 사용, 품절 상태표는 Notion table로 변환
- `안전 재고 설정`: 설명은 Notion list, 화면 예시는 이미지로 분리

## 6. 어노테이션 처리 기준

어노테이션 자동 해석은 MVP의 필수 범위가 아니다.

MVP에서는 다음처럼 처리한다.

- PPT 객체 분석으로 어노테이션 후보를 감지한다.
- 화면 이미지와 겹치는 강조 박스/번호는 후보 이미지에 포함할 수 있다.
- 큰 화살표나 본문 연결선은 기본 제외한다.
- 연결성은 Notion numbered list와 캡션으로 표현한다.

## 7. 표 처리 기준

표는 누락 금지 대상이다.

우선순위:

1. PPT table 객체를 Notion table로 변환한다.
2. PPT table 객체가 아니지만 격자/행열 구조가 보이면 table 후보로 표시한다.
3. table 변환이 실패하면 표 영역 이미지를 fallback asset으로 만들고 `table_review_required`를 남긴다.

표를 완전히 제외하는 것은 허용하지 않는다.

## 8. Notion 블록 순서 기준

Notion 문서는 PPT의 시각 배치를 그대로 복제하지 않는다. 사용자가 문서를 위에서 아래로 읽을 때 자연스러운 순서를 우선한다.

권장 순서:

1. 페이지/섹션 제목
2. 단계 설명
3. 관련 화면 이미지
4. QR/링크/표
5. 주의사항 또는 참고

## 9. 검수 기준

변환 결과는 발행 전 아래 기준을 만족해야 한다.

- 텍스트가 이미지에만 갇혀 있지 않다.
- QR이 플랫폼별로 분리되어 있다.
- 표가 누락되지 않았다.
- 이미지가 본문 설명을 중복 포함하지 않는다.
- Notion 페이지에서 읽는 순서가 PPT 없이도 자연스럽다.
